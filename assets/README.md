|---|---|---|
| `polaris_logo_clean.png` | Primary Polaris wordmark + glyph; navy + gold | `README.md` (top of file) |

---

## Conventions

- PNG for raster (logo); SVG for new vector work
- Filenames lowercase + `_`-separated
- No `.DS_Store` or other macOS artifacts (gitignored at root)
- Source files (e.g., Figma exports) not tracked here; only
  shipped artifacts

---

## What this directory is NOT

- Not generated or build artifacts
- Not user-uploaded content (Polaris is server-side rendered;
  no user uploads)
- Not the academic paper PDF (that's in [`../docs/paper/`](../docs/paper/))

`assets/` is **the visual identity surface** — what makes Polaris
recognizable as Polaris.
