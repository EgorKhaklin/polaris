## I. The Matter

After the v9.15 brain-map update made the Mycelium fully visible,
VANTA observed that several "open" arcs carried stale labels:

| Arc | Pre-v9.16 label | Reality |
|---|---|---|
| Arc B (production) | "Open (Phase 1 shipped 2026-05-14 as v8.77)" | Phase 1 ✅; Phase 3 Wave 1 ✅ (v9.01); Phase 2 + Phase 3 remainder genuinely waiting on triggers |
| Arc E (Mycelium) | "active, opened 2026-05-13" | All phases shipped through v9.11; functionally complete |
| Arc F (Denarius) | "active, opened 2026-05-13; closed 4/4 then reopened with F5 amendment" | F1-F5 all shipped (F5 amendment delivered v8.73); functionally complete |
| Arc G (Empire) | "active multi-day, opened 2026-05-13" | Phase 1 ✅ shipped v8.71; Phase 2 + Phase 3 "deferred indefinitely" — speculative scaffolding that hasn't materialized |

Audit-of-record discipline (v8.20) requires constitutional docs to
not contain lies. The "active" labels on Arc E + Arc F are stale
to the point of dishonesty.

The question: close them all? Reclassify? Truth-update? Leave?

## I.0 Vocation alignment (per v9.11 protocol)

The proposal *to fix the labels* is anti-coercion-aligned: identity
that cannot be compelled requires institutional honesty, and the
system's own constitutional state is part of its institutional
identity. Lies in AoR docs corrode the principle that makes AoR
load-bearing.

The proposal *to manage the deferred phases* is more neutral. None
of Arc B Phase 2, Arc G Phase 2, or Arc G Phase 3 advances
anti-coercion directly. They are scaling / governance scaffolding
that *might* serve the vocation eventually but does not today.

## II. The architect's positions (four; with Anti-Architect Position E added in §III)

### Position A — Close-out via three Sanctums (one each for E, F, G)

Formally retire each arc with a closing Sanctum. Arc B kept open
(real deferred work). G's Phase 2/3 retired as terminal.

**Strengths:** Clean. Constitutional weight. Operator load drops permanently.
**Weaknesses:** Three new Sanctums while the Anti-Architect is already
flagging AP2 (Sanctum-overuse). Constitutional weight for
housekeeping. "Terminal-deferred" is new vocabulary.

### Position B — Reservation pattern broadly applied

Extend the v9.11 twelfth-legion RESERVED pattern to all deferred
phases. Each becomes a held-silence node.

**Strengths:** Reuses existing pattern. Preserves optionality.
**Weaknesses:** AP7 risk — the twelfth-legion reservation was justified
by ONE specific case. Generalizing is the canonical premature
abstraction.

### Position C — Two-track (close functionally-complete; truth-update the rest)

Close Arc E + Arc F (functionally complete). Truth-update Arc B and
Arc G with honest Status lines.

**Strengths:** Honest about each arc's actual state. No new
Sanctums beyond this one. No new vocabulary.
**Weaknesses:** Two-state model is more vocabulary than uniform
close-out. Arc G trigger conditions need to be defensible.

### Position D — Leave as-is

Honor existing state.

**Strengths:** Zero work.
**Weaknesses:** "active" labels on Arc E + Arc F are documented lies.
The Anti-Architect — normally an inaction-endorser — disagrees here:
lies in AoR corrode the AoR principle.

## III. Architect's recommendation + Anti-Architect's contest

**Architect recommended Position C.** The minimum-truth path that
fixes actual drift without inventing new state-machine vocabulary.

**Anti-Architect contested specific elements:**

- **Position A:** trips AP2 (3 more Sanctums in an already-Sanctum-heavy
  cadence), AP3 (cognitive-layer self-elaboration), AP5 (vocation
  drift — closing Arc G Phase 3 doesn't advance anti-coercion).
  Strong refusal.
- **Position B:** trips AP7 (premature abstraction; twelfth-legion
  reservation was earned by one specific case), AP4 (pattern
  projection onto noise; Arc B Phase 2 doesn't map cleanly to the
  reservation idiom). Strong refusal.
- **Position C close-side (E + F):** endorsed. Labels are lies; fixing
  is honest.
- **Position C truth-update Arc B:** endorsed. Real-world triggers
  (prod-scale data; partner request) are concrete external conditions,
  not speculation.
- **Position C truth-update Arc G:** **proposed refinement.** Arc G's
  Phase 2/3 are not "deferred" — that implies *planned but not yet*.
  The honest framing is **RESERVED-NOT-PLANNED**: the structural slot
  exists but Polaris is not planning toward it. Operator may manifest
  via Sanctum when real need surfaces (mirrors the v9.11
  twelfth-legion manifestation protocol).
- **Position D:** Anti-Architect's normal preference for inaction;
  here disagrees because AoR-lies are AoR-corrosion.
